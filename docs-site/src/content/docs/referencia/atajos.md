En Windows, **Ctrl** sustituye a **⌘**.

## Escritura

| Atajo | Qué hace |
| --- | --- |
| ⌘B | Negrita |
| ⌘I | Cursiva |
| Tab | Anida el punto de lista (o sangra las líneas seleccionadas) |
| Mayús+Tab | Saca el punto de lista un nivel |
| Intro en una lista | Continúa la lista con la misma viñeta o el número siguiente |
| Esc, luego Tab | Saca el foco del editor (Tab sola sangra) |
| ⌘Z / ⌘⇧Z | Deshacer / rehacer |

## Fichas

| Atajo | Dónde | Qué hace |
| --- | --- | --- |
| Coma o Intro | Campo *Tags* | Añade el tag |
| Retroceso | Campo *Tags* vacío | Quita el último tag |
| Esc | Fichero | Cierra el panel de la ficha |

## Formularios y diálogos

| Atajo | Dónde | Qué hace |
| --- | --- | --- |
| Intro | *Rellenar con un DOI o un ISBN* | Busca |
| Intro | *n.º impreso* (paginación) | Corrige |
| Intro | *Hoja _n_ de _N_* (lector) | Salta a esa hoja |
| Esc | Ajustes, menú Exportar, nombre de un texto o fichero | Cierra o cancela |
